# 8 分钟 Demo 脚本（V2.1 验收 / 汇报 / 回归共用）

> 演示纪律：**默认只用 mock（`ENGINE=mock`）+ 预置数据**，不现场连接真实邮箱。
> 真实模型段落是可选加分项，演示前单独彩排；现场网络不可控时跳过，不影响主链路。
>
> 准备：
> 1. 按 README「10 分钟启动」起好 api（8000）与 web（5173）；
> 2. `curl -s http://127.0.0.1:8000/api/v1/health` 确认 `status=ok`；
> 3. 生成演示素材：`.venv/Scripts/python.exe scripts/make_sample.py`；
> 4. 浏览器 1440×900，打开 `http://127.0.0.1:5173`，清空旧会话（或用一个新会话）。

## 备用台词（被追问时）

- **「为什么默认 mock？」** 演示要可复现；真实模式已实现（`ENGINE=real`），失败自动降级并标 `degraded`。
- **「产物会发出去吗？」** 不会。本版没有任何外部发送能力，产物只写本地产物目录；审批拒绝时零写入。
- **「能多用户吗？」** 本版主动不做（计划书 §2.4）；设置中心/审计/产物中心已按单用户闭环。
- **「断线会丢事件吗？」** 不会。事件先落 `run_events` 再推送，重连带 `Last-Event-ID` 回放 `> seq`（30s 内）。
