# ADR 0002：mock 先行，外部依赖可降级

- 状态：已采纳（D2）
- 日期：2026-10-22
- 决策人：A / B / C
- 影响面：模型调用、邮件连接器、演示可靠性、CI

## 背景

本版有两个不可控外部依赖：模型 API（网络、配额、费用）与邮箱（授权链路长、真实外发有风险）。
如果主链路依赖它们，前端开发会被后端阻塞，演示会被现场网络否定，CI 无法离线跑。

## 决策

1. **`MOCK_MODE=true` 是一等公民**：默认配置即 mock，断网可完整演示全链路。
2. **mock 不是空壳**：内置确定性脚本引擎按固定剧本产出计划、工具调用、审批、
   DOCX 产物与用量数字，SSE 时序与真实模式一致（含 `message.delta` 流式增量）。
3. **真实模式只换装配**：`MODEL_PROVIDER` / `OPENAI_API_KEY` / `OPENAI_BASE_URL` 决定模型；
   模型实现由 `providers/` 工厂按供应商选择，主流程零分支。
4. **失败自动降级**：真实模型超时/限流时回退 mock，事件带 `degraded:true`，前端顶部提示
   「当前使用演示模式」，不中断演示。
5. **零外部副作用**：本版不提供邮件/IM 等外发能力；产物只写本地产物目录，审批拒绝时不产生任何写入。

## 备选方案与不采用原因

| 方案 | 不采用原因 |
|------|------------|
| 先接真实模型再补 mock | 前端被阻塞、费用不可控、离线无法演示 |
| 用录制的真实响应做 cassette | 依赖录制时的提示词与模型版本，脆弱且无法覆盖审批分支 |
| 直接调真实邮箱测试 | 真实外发不可撤销，演示风险不可接受 |

## 后果

- CI 与本地测试零外部依赖，`pytest` 可离线跑（见 `tests/README.md`）。
- 演示纪律：只用 mock 连接器（见 `docs/demo.md`）。
- 代价：mock 输出是固定剧本，不能验证真实模型的规划质量；真实模式的质量评估留给 V1.0。

## 验证方式

- 断网（或 `MOCK_MODE=true`）跑 `pytest tests` 全链路用例。
- `curl /api/health` 返回 `mode: "mock"`。
- 演示前检查清单：断开网络仍能走完 5 分钟 Demo。
