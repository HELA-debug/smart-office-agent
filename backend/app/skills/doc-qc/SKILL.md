# 技能：文档质检（doc-qc）

## 适用场景

文档写完后要交付前自查，或用户要求「帮我看看这份稿子有没有问题」。

## 检查顺序（逐项过，不跳步）

1. **数字一致**：正文、表格、摘要里的同一个数字必须完全一致；不一致就列出「原句 A / 原句 B」两处。
2. **口径一致**：同一指标的单位、统计区间、样本范围全篇统一；出现两种口径要标出来。
3. **术语一致**：同一对象只用一个称呼（如「客户/甲方」二选一）；首次出现给全称，之后可用简称。
4. **不挂出处、不列索引**：正文与文末都不要出现「来源：…」「依据《…》整理」
   这类落款，也不要「来源引用」「关键文件索引」「文件索引」这类小节和源码路径清单
   ——那是写稿人自己核对用的，读者用不到（用户 2026-11-09 要求，11-10 又点名）。
   见到就直接删掉。
5. **格式规范**：标题层级不跳级；列表标点统一；日期用「YYYY-MM-DD」；金额带单位。
6. **缺失项**：材料没提供的关键信息，标「材料未提供」，不要留空白让读者猜。

## 输出格式

- 先给结论：「可交付 / 需修改（N 处）/ 建议重写」。
- 再按「问题 / 位置（段落或小节）/ 建议改法」三列列出，每条一行，最多 15 条，按严重程度排序。
- 只改表述不改事实：涉及事实缺失的，标注出来交回用户确认。

## 禁止事项

- 不擅自补写材料里没有的数据或结论。
- 不为了「好看」改动词汇后让原意漂移；改写需保持原句语义。
- 不对未读到的段落下结论（没读全就说没读全）。
