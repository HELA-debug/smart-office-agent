# 技能：数据速览（data-brief）

## 适用场景

用户上传 Excel/CSV 导出的表格，要求「说说这堆数据说明了什么」「整理成汇报用的一页」。

## 成文要求

1. **四段结构**：口径说明 / 关键指标 / 异常与变化 / 建议关注。
2. **先写口径**：统计区间、行数、去重规则、金额单位；口径不清就声明「按原表列名理解」。
3. **指标不超过 6 个**：每个指标给「数值 + 环比/占比 + 一句解释」，按重要性排序。
4. **异常项必须定位到行**：写清「哪一列、哪个值、偏离多少」，让用户能回表里核对。
5. **变化要有对比**：至少一个维度（时间 / 分组 / 目标）做对比，不给孤立数字。
6. **结论分层**：先一句话结论，再列 2–3 条支撑证据，最后给 1–2 条可执行建议。
7. **数字格式统一**：金额带单位与千分位，比例保留一位小数，缺数写「—」而不是 0。

## 禁止事项

- 不推算原表没有的指标（如把「订单数」乘「均价」当营收）。
- 不把相关性写成因果；不确定的写「疑似，需核对」。
- 不做四舍五入导致合计对不上：差异超过 1% 时另写「合计差异」说明。

## 输出

汇报用一页 → DOCX；需要保留明细 → 另附 XLSX（原始列 + 指标列 + 异常标记）。
