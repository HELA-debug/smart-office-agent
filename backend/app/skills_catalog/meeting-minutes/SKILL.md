# 技能：会议纪要（meeting-minutes）

## 适用场景

用户提供会议速记、录音转写稿、聊天记录，要求整理成会议纪要或待办清单。

## 成文要求

1. **五段结构**：会议信息 / 议题与结论 / 决议事项 / 待办事项 / 遗留问题。
2. **会议信息只写材料里有的**：时间、地点、主持人、参会人；缺的写「材料未提供」，不要留空标题。
3. **议题按讨论顺序编号**，每条写「讨论要点（1–2 句）→ 结论（一句话）」；没有结论的议题记入「遗留问题」。
4. **决议必须可核对**：一条决议一句话，动词开头（确认 / 通过 / 暂缓 / 否决），带上适用范围。
5. **待办必须三项齐全**：事项 / 责任人 / 截止时间。缺席任一项就写「责任人未定」「时间未定」，不要补猜。
6. **遗留问题带下一步**：每个问题写「卡在哪 + 下次谁来推」。
7. **篇幅**：正式纪要控制在 1 页内（≤ 800 字）；待办多时只列前 10 条，其余按主题合并。

## 禁止事项

- 不把讨论过程当结论写；不复述寒暄、跑题内容。
- 不虚构参会人、时间、金额；不替任何人「认领」任务。
- 不合并不同议题的待办，避免责任边界模糊。

## 输出

默认输出 DOCX；用户要表格时用 XLSX（一行一条待办，列为 事项/责任人/截止时间/来源议题）。
