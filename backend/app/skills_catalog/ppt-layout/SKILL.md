# 技能：幻灯片排版（ppt-layout）

## 适用场景

要做一份要投到屏幕上讲的 PPT：汇报、复盘、路演、答辩、培训。
生成用 `doc_generate_report(format="pptx")`（正文交给它按小节成页），或
`code_run_python` + `pptx_utils.write_deck`（自己排每一页）。

## 一、幻灯片和文档不是一回事

文档是给人**读**的，幻灯片是给人**看**的。所以：

- 文档一页能放 800 字，幻灯片一页最多 6 条、一条不超过 42 个字。
- 文档可以铺陈推理，幻灯片只放**结论**：推理过程你说，页面留结论。
- 文档的小节是章节，幻灯片的一页是**一个观点**。一页讲两件事，观众两件都记不住。

**先写一句话主张**：这份 PPT 讲完，听众应该记住哪一句？这一句就是封面副标题，
也是每页标题要往回扣的东西。扣不上的一页，删掉。

## 二、结构：开头三十秒定生死

| 页 | 装什么 | 不要装什么 |
|---|---|---|
| 封面 | 标题 + 一行副标题（谁 / 什么时候 / 给谁看） | 要点、目录、公司简介 |
| 目录 | 三到六条，一条一个词 | 整句、解释 |
| 章节页 | 整页只写「一、进展」 | 内容 |
| 正文页 | 一页一个观点 + 3–6 条证据 | 两个观点、整段文章 |
| 数据页 | 三到五个大数字 + 一行口径 | 一张 20 行的表 |
| 结论页 | 一句话结论 + 要他做的一件事 | 「谢谢观看」 |

- 总页数 ≈ 讲的时间（分钟）× 1 到 1.5。20 分钟的汇报塞 40 页，等于每页 30 秒，没人跟得上。
- 正文页超过 12 页要回头合并：多数「内容多」其实是「没想清楚要说什么」。
- 结尾不要「谢谢观看」，写「需要你确认的一件事」——会议开完要有下一步。

## 三、每页怎么写

- **标题写结论，不写话题**。写「退款率降到 1.2%，仍高于目标」而不是「退款率分析」。
  标题是这一页的论点，不是目录项。
- 标题不超过 22 个字；超过说明这一页想讲两件事。
- 要点是**证据**，不是标题的复述：标题说结论，要点给数字、对比、出处。
- 一条要点一行放得下（约 42 个汉字），放不下就拆成两条或降为讲稿。
- 一页六条封顶。第七条开始，后排观众已经在看手机。
- 讲稿放备注（speaker notes），不要塞进页面。页面是提醒，嘴里才是内容。

## 四、字号与配色

| 元素 | 字号 | 说明 |
|---|---|---|
| 封面主标题 | 40pt | 一页只有它，可以大 |
| 内页标题 | 36pt | 后排能一眼扫到 |
| 正文 / 要点 | 20pt | 投影可读下限，别再小 |
| 副标题 / 说明 | 20pt | 比正文淡一档颜色 |
| 表格 | 14pt | 再大就装不下 |
| 图注 / 页脚 | 12pt | 口径、来源、页码 |

- **字号小于 18pt 的正文，投影出来等于没有**。装不下就减字，不要缩字号。
- 画幅默认 16:9；老会议室或要印讲义用 4:3（`slide_size("4:3")`）。
- 配色四色够用：底、标题、正文、强调。强调色全篇只表达一件事（通常是结论）。
  可选主题：商务蓝（默认）/ 极简 / 深色 / 党政红 / 学术，见 `slide_lexicon.THEMES`。
- 一页最多两种字号层级加一个强调色。三种以上颜色，观众会去找图例。

## 五、要不要放图、放表

- 图比表好，表比字好，字比空话好。能在页面上放一张图，就不要写五行描述。
- 表格超过 5 列 × 6 行就挪到附录，正文只留一句结论。
- 数据必须带口径和单位：`1.2%（本周，样本 3,480 单）`。只写 `1.2%` 的数是装饰。
- 图不要加边框和阴影；一页只放一张图。

## 六、交付前自检（逐项过）

1. 只读封面和目录，能不能知道这份 PPT 要讲什么？
2. 每页标题是不是「结论句」？有没有一页标题只是个名词？
3. 有没有哪页超过 6 条要点、或者正文小于 18pt？
4. 有没有一页讲了两件事？拆开或删掉一件。
5. 每个数字都有口径、单位、时间吗？
6. 结论页有没有写清「要他做什么」？
7. 全篇颜色和字号是不是一套？有没有从别处粘来的异色块？
8. 投影出来最后一排能不能看清？（字号 < 18pt 的正文，答案是不能）

## 禁止事项

- 不把 Word 的段落整段粘进幻灯片。
- 不用艺术字、渐变背景、动画（除非用户明确要求）。
- 不写「谢谢观看」「欢迎批评指正」这类结尾页。
- 不把内部口径（生成时间、模型名、run_id）写进页面。
