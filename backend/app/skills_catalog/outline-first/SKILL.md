# 技能：先立提纲（outline-first）

## 适用场景

方案、报告、白皮书这类长文（≥ 2000 字）：用户还没想清结构，或要求「先给个大纲」。

## 成文要求

1. **先给一句话主张**：这篇文章要读者记住的一句话结论，20 字以内。
2. **提纲两级封顶**：一级 4–6 个，二级每个 2–4 条；超过两层就说明结构该合并。
3. **每个二级标题后面挂素材**：写明「用哪份材料的哪一段」，没有素材的标注「待补」。
4. **顺序按读者决策走**：结论 → 依据 → 风险 → 动作，不要按收集顺序罗列。
5. **每个一级标题写一句「读完这段读者应该知道什么」**，写不出来就删掉这段。
6. **篇幅预估**：每节给目标字数，合计与用户要求的总篇幅对齐（±10%）。

## 检查清单

- 提纲任意两条能否互换位置？能互换说明排序没有逻辑，需要重排。
- 有没有只放背景、没有结论的章节？合并或删除。
- 「待补」超过 3 处时，先回头找用户补素材，不要硬写。

## 禁止事项

- 不在提纲阶段就开始写正文段落（用户要的是结构，不是成稿）。
- 不堆砌同级标题凑数；宁可少一节也不要空话。
- 不承诺材料支撑不了的内容（如没有数据却写「效果显著」）。
