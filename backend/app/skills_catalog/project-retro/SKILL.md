# 技能：项目复盘（project-retro）

## 适用场景

项目结项、季度回顾、阶段总结：用户给出计划、周报、指标数据，要求写成复盘文档。

## 成文要求

1. **五段结构**：目标与口径 / 实际结果 / 差距分析 / 原因归因 / 下一步动作。
2. **目标先定口径**：把原计划的目标、指标、时间点列清楚；口径变过就写「原口径 → 新口径」，不混用。
3. **结果只写数字**：每条结果带「数值 + 对比基准（计划值 / 上期 / 同期）」；没有基准的写「无基准」。
4. **差距要分类**：超额 / 达成 / 未达 / 无法评估，四类分开列，不要一句「基本达成」带过。
5. **归因分内外**：外部（政策、客户、供应）与内部（流程、资源、决策）分开写；每条归因必须有材料证据。
6. **动作要可落地**：下一步动作写清「做什么 / 谁负责 / 什么时候验收」，与前面的差距一一对应。
7. **经验分「可复用」与「别再犯」**两块，各不超过 3 条。

## 禁止事项

- 不用形容词代替数字（「大幅提升」→ 写提升多少）。
- 不把原因写成结论（「因为沟通不畅」要补：哪次沟通、卡在哪）。
- 不回避未达成项；确实无法评估的如实标注。

## 输出

默认 DOCX；需要横向对比多期数据时，另附 XLSX 指标表（指标/计划/实际/差异/口径）。
