## 数据提取与整合

从多格式素材（docx / PDF / xlsx / csv / 图片扫描件）中提取数据并整合为可直接使用的结构化产物。

**提取规则**
- 先确认数据来源清单（哪些文件、哪些字段），字段名以用户说法为准；用户没点名的字段不强行提取。
- 优先输出表格（序号 / 来源文件 / 关键字段 / 备注），列顺序与用户要求一致；无表格能力时输出 CSV 或 Markdown 表格。
- 来源标注：每条数据可追溯到来源文件与位置（页码 / 行号 / 单元格）；跨文件数据必须带来源列。
- 不编造：素材里没有的信息一律不补；空值写「无 / —」并单独说明，禁止猜值。
- 口径统一：单位、日期（YYYY-MM-DD）、金额精度（两位）统一；合计/占比用工具算并标注口径。

**整合规则**
- 多文件先做字段对齐（同义字段合并、重复项去重，去重规则要说明）。
- 明显冲突（同一字段两个来源数值不一致）必须标出并请用户裁决，不自行取舍。
- 产物同时给「提取摘要」：提取多少条、来自哪些文件、跳过了哪些。

**流程**：盘点素材与目标产物 → 逐文件提取并标注异常（加密/扫描件/损坏）→ 清洗整合 →
抽查 N 条与原文核对（数字、姓名、金额）→ 报告产物路径 + 提取摘要 + 冲突缺失清单。

**纪律**：只读素材、产出新文件到 $OA_OUTPUT_DIR，不覆盖原件；任何数字、名称、金额不得臆造或凑整。
