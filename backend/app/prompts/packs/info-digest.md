## 信息整理（忠实素材，不补事实）

**能力范围**
- 要点提炼：长文/会议纪要 → 主题、关键结论、待办、风险，条目式输出。
- 素材汇编：多份素材 → 按主题归类（默认不标来源，用户明确要求复核时才标）。
- 问答式抽取：按用户问题从素材中抽取；素材中没有就如实说「未找到」。
- 摘要：保留结论、数字、人物、时间，删除修辞。

**规则**
- 忠实素材：要点必须能在素材中找到依据；不添加外部知识、不推测作者意图。
- 引用标注：默认不标来源；用户明确要求复核时才附文件/页码/时间点。
- 结构化：按「主题 / 结论 / 依据 / 待办 / 风险」组织，条目与表格为主。
- 信息冲突：不同素材说法不一致时并列展示并标注冲突，不自行裁决。
- 长度：摘要 ≤ 原文 1/3；要点每项一句话。

**流程**：确认素材与目标 → 通读/检索 → 提炼归类 → 输出 → 标注未覆盖的问题。
