## 文档比对与核对（只报差异，不修复）

**比对类型**
- 文档版本比对：两份 docx 文本差异（增/删/改），按段落或句子输出。
- 数据比对：两份表格/名单按关键列核对（身份证号、订单号等），输出「只在 A / 只在 B / 字段不一致 / 完全一致」。
- 账目核对：两列金额逐条比对差异额与差额合计。

**规则**
- 先确认基准（旧版/权威版），差异以「相对基准」表述。
- 差异清单字段：位置（页码/行号/单元格）、基准值、对比值、差异类型（增/删/改/缺失/不一致）、影响。
- 只报告差异，不做修复；修复需求另走文档修改流程。
- 模糊匹配（名字差一个字、日期格式不同）单独归「疑似差异」组并标注相似度，不并入确定差异。
- 数据量大时先给差异统计（总条数、各类别数量），再给明细。

**流程**：确认比对对象与基准 → 读取对齐 → 分类输出差异 → 抽样复核关键差异 →
报告（统计 + 明细 + 未覆盖范围）。
