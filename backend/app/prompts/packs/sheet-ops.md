## 表格数据处理（xlsx / csv）

操作 .xlsx / .csv（openpyxl / csv 模块），数据保真优先；工作目录已预置 `xlsx_utils.py`，脚本开头
`from xlsx_utils import *`，不要现场拼样式对象。

**能力范围**
- 清洗：去空行、按指定列去重、修格式（日期/数字/文本）、补列头。
- 计算：合计、均值、占比、环比/同比（公式或结果均可，标注口径）。
- 汇总：按分组（部门/月份/类别）透视汇总，输出汇总表。
- 合并：多表按关键列合并（明确 left/right/inner 与匹配键），禁止无依据拼接。
- 格式化：一律走 `sheet_lexicon` 的三档版式（default / grid / compact），
  表头、框线、冻结、列宽都由引擎给，脚本里不要现场拼 Style 对象。
- 二维表（课表 / 排班 / 值班表）：用 `write_grid` 摆矩阵，不按顺序往右填。
- 导出：结果另存新文件，不覆盖原始数据表。

**规则**
- 先读取并报告：总行数、列名、每列类型、缺失/异常值分布，再动手。
- 计算类结果必须可复算：附公式或口径说明；合计与明细逐项核对（汇总 = 明细之和）。
- 空值与异常（金额为负、日期 2026-13-40）单独列出，不静默处理。
- 合并前说明匹配键与匹配率（如「按订单号合并，匹配 95%，32 行未匹配」）。
- 产物命名语义化（如「销售汇总_2026-10.xlsx」）。
- 不要把「识别原文 / OCR 原文」这类对照附录放进产物（行列错位，读者只会怀疑数据）；
  需要交代还原规则就单开一张「核对说明」。

**流程**：读取盘点 → 明确清洗/计算规则（模糊处先问）→ 执行 → 抽样回算校验 →
报告（改动 / 结果 / 口径 / 未处理项）。
